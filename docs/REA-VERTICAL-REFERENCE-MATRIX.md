# NaijaDeals Vertical-to-Reference Matrix

**Evidence rule:** A reference product is not marked REA-inspected unless an authorized REA target/session was actually available and inspected. During this audit, no REA command, competitor app target, APK, emulator, authorized account, or source repository was available. The reference column therefore separates product hypotheses from evidence.

**Status vocabulary:**

- **Implemented:** source route, backend/data path, and usable workflow are present in this worktree.
- **Partial:** some real backend or UI exists, but the vertical or lifecycle is incomplete.
- **Preview/registry:** discoverable or rendered, but no verified vertical-specific operational backend.
- **Unavailable:** a required runtime/provider is deliberately unavailable.
- **Missing:** no dedicated vertical implementation was found.
